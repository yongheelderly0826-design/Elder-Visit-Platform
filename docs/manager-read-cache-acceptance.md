## 附錄 A — 技術管理員快速 API 抽驗

在專案根目錄（需 `.env.local`）：

```bash
GAS_URL=$(grep '^GAS_WEB_APP_URL=' .env.local | cut -d= -f2-)
GAS_TOKEN=$(grep '^GAS_API_TOKEN=' .env.local | cut -d= -f2-)

# 匯出 bundle（應有 candidates + payments + counts）
curl -sSL "${GAS_URL}?action=export.managerBundle&only_audited=true&token=${GAS_TOKEN}" | head -c 400

# 連打兩次比秒數（第 2 次應較快）
time curl -sSL -o /dev/null "${GAS_URL}?action=export.managerBundle&only_audited=true&token=${GAS_TOKEN}"
time curl -sSL -o /dev/null "${GAS_URL}?action=export.managerBundle&only_audited=true&token=${GAS_TOKEN}"
```

**預期**：第 2 次 `real` 時間明顯短於第 1 次；JSON 內 `candidates.total ≥ 1`。
