訪查員自領多案流程｜依里編號連領

方案 B｜實地訪查時一次領多案，於任務列表逐案簽到並 KEY 關懷表

領案模式：B 依里編號連領
來源標記：訪員自領・實訪
池來源：個案名冊尚無進行中派案
無「今日路線清單」步驟
訪查員登入 進入既有「訪員任務」畫面
訪員任務（卡片列表） 可查看進行中任務，或開始一次領多案
一次領多案 方案 B：依里編號連領（非真隨機）
輸入里編碼＋領取數 N 例：里編碼 040051；領取數 N＝想一次帶走幾筆
自該里「尚無進行中派案」池連領 依 village_seq（里編號）由小到大，連領最多 N 筆
可領筆數是否足夠？／有無衝突？
池中 ≥ N
連領 N 筆成功 派案寫入；擋別人已有進行中派案
池中 < N 或衝突
有幾筆領幾筆並提示 不足 N 時告知實際領取數；衝突案跳過
回到訪員任務卡片列表 新領案件出現在列表；不另開「今日路線」
（可選）預排時段顯示於卡片 訪視約 10 分＋路途約 5 分，僅供參考，可略過
逐案循環：到宅簽到 → KEY 關懷表 完成一案後回任務列表，選下一案繼續
今日領取的案都完成了？
收工／核銷鉤稽 以 assignment_id＋visitor_id 對帳；來源：訪員自領・實訪

資料來自 Google Sheets 個案名冊（village_code、village_seq、case_id）；派案表擋「別人已有進行中派案」。
鉤稽鍵：assignment_id + visitor_id｜永和區獨居長者訪查管理平台
