## 5. 標準作業流程

本平台有兩條並行流程，**勿混用**：

```
【訪查流程】個案建檔／匯入 → 派案 → 關懷表登打（或空訪）→ 稽核 → 衛福部 xlsx → 車馬費核銷

【志工出勤】名冊建檔（身分＋組別）→ 外勤掃 QR／公所刷證 → 月結 Excel → 匯入既有出勤系統
```

### 5.1 承辦人每日建議順序

1. **先處理待派案**：高風險個案優先分派  
2. **追待補件**：缺定位、同意書、照片者通知訪員  
3. **完成稽核**：可通過者往核銷階段  
4. **鎖定匯出**：僅匯出已通過稽核之資料  
5. **（另線）志工出勤**：月底下載月結 Excel 匯入既有系統  

總覽頁（`/dashboard`）會顯示訪查各步驟件數；出勤請進 **志工出勤**。

### 5.2 個案名冊

1. 進入 **名冊**（`/manager/cases`）  
2. 可搜尋姓名、編碼、里別、訪查狀態  
3. 115 年試運行已匯入 **56 筆**測試個案（編碼格式 `CASE-YH-*`、去識別化 `YH-115-A001` 等）  
4. 新增或修改後，資料即寫入 Google 試算表「個案名冊」工作表  

### 5.3 批次匯入

1. 進入 **匯入**（`/manager/import`）  
2. 上傳符合欄位規格之 CSV（可參考倉庫 `sheets/templates/`）  
3. 預覽無誤後確認匯入  
4. 匯入結果可在名冊與試算表核對  

### 5.4 派案

1. 進入 **派案**（`/manager/assignments`）  
2. 依里別、優先序、訪員選擇待派案件  
3. 確認派案後，訪員於 **任務** 頁可見新任務  

### 5.5 訪員訪查（行動端）

1. 訪員登入後開啟 **任務**  
2. 抵達個案處填寫關懷表或標記空訪（建議開啟定位／上傳照片）  
3. 送出後若缺照片或同意書，狀態會進入「待補件」  
4. 訪查簽到退與「12 組志工出勤」分開；後者見 **5.7**  

### 5.6 稽核與匯出

1. **稽核**頁檢視待審案件（通過／退回補件／駁回）  
2. 通過後關懷表狀態為「已稽核」  
3. 至 **匯出** 勾選「僅稽核通過」產生衛福部 102 欄 xlsx  

### 5.7 12 組志工出勤（外勤 QR／公所刷證）

適用：送餐、道路維護、公園綠化等**沒有電腦**的外勤組，以及公所內勤刷證。

#### A. 承辦準備（一次）

1. 進入 **志工出勤**（`/manager/attendance`）  
2. 在「志工名冊」新增：姓名、身分證、電話、組別（12 組之一）  
3. 列印「集合點 QR 海報」，張貼於各組集合處  

#### B. 外勤志工（手機）

1. 用手機相機掃描集合點 QR，或開啟 `/volunteer/clock?site=SITE-MEAL`（範例：送餐組）  
2. 第一次先輸入**身分證字號**登入（系統記錄身分與組別）  
3. 確認地點後按 **簽到**；下班再掃同一 QR（或再開頁面）按 **簽退**  
4. 同一天未簽退時，再操作一次即為簽退  

#### C. 公所內勤（電腦）

1. 承辦／內勤以管理者帳號登入  
2. 開啟 **刷證櫃台**（`/office/kiosk`），讓掃描器游標停在輸入框  
3. 刷身分證條碼（自動送出）→ 顯示簽到或簽退成功  

#### D. 月結匯出

1. 進入 `/manager/attendance`，選擇月份  
2. 按 **下載 Excel**  
3. 將檔案匯入公所既有出勤／結算系統  

| 匯出欄位 | 說明 |
|----------|------|
| 年月、組別、姓名、身分證字號、志工編號 | 身分與組別 |
| 日期、簽到時間、簽退時間、出勤時數 | 出勤時段 |
| 簽到方式、地點、出勤編號 | 外勤QR／公所刷證、集合點 |

> 若貴單位有固定匯入範本欄位，請提供檔案給系統管理員對欄。

> **給其他管理員的教育訓練**：請見本手冊 **§9**；列印勾選表見 [`volunteer-attendance-e2e-acceptance.md`](./volunteer-attendance-e2e-acceptance.md)。

## 7. 常見問題

### Q1：登入顯示「不允許的帳號」？

承辦 Gmail 須在系統允許清單內。試運行請使用 `yongheelderly0826@gmail.com`。若需新增同事 Gmail，請聯繫系統管理員更新環境變數 `GOOGLE_ALLOWED_EMAILS` 並重新部署。

### Q2：名冊顯示 104 筆假資料，不是 56 筆真實資料？

表示網站未連上 GAS。請確認 Vercel 已設定 `GAS_WEB_APP_URL`、`GAS_API_TOKEN` 並完成 Production 重新部署。正常狀態下系統頁（`/system/status`）應顯示 `dataMode: gas_ready`。

### Q3：兩人同時操作會衝突嗎？

資料共用同一份試算表，可同時使用，但請避免兩人同時編輯**同一列**個案。

### Q4：忘記 GAS Token 怎麼辦？

請勿將 Token 貼在公開處。向已設定 `.env.local` 之管理員索取，或至 Google Apps Script 專案重新產生 API Token 並更新 Vercel 環境變數。

### Q5：離線能用嗎？

訪員 PWA 支援部分離線草稿，正式送出仍需網路。詳見 `docs/pwa-offline-checklist.md`。

### Q6：外勤掃 QR 顯示找不到志工？

請承辦先在 **志工出勤** 建檔（姓名、身分證、組別）。未建檔無法登入簽到。

### Q7：訪查簽到跟志工出勤有什麼差別？

| | 訪查作業 | 12 組志工出勤 |
|--|----------|----------------|
| 目的 | 獨居長者關懷表 | 組別出缺勤結算 |
| 入口 | `/visitor/tasks` | `/volunteer/clock`、`/office/kiosk` |
| 身分依據 | 訪員帳號／派案 | 身分證＋組別 |
| 月結 | 衛福部 102 欄 | 出勤 Excel（匯入既有系統） |

### Q8：公所刷證沒反應？

確認已用承辦帳號登入、游標在刷證輸入框，且掃描器為「鍵盤模式」（刷完自動 Enter）。

### 9.5 實作二：承辦建檔與 QR（學員跟著做）

1. 登入 https://elder-visit-platform-ruby.vercel.app/login  
2. 開啟 **志工出勤** `/manager/attendance`  
3. 新增 T-MEAL、T-OFF（姓名、身分證、電話、組別）  
4. 確認名冊出現兩人；可至試算表「訪查員主檔」核對 `volunteer_group`  
5. 在頁面找到「集合點 QR 海報」，確認有送餐組等海報；用手機掃「送餐服務組」QR，應開到帶 `site=SITE-MEAL` 的簽到頁  

**通過標準**：兩筆建檔成功；掃 QR 可開外勤頁且顯示地點名稱或代碼。

### 9.6 實作三：外勤掃 QR 簽到／簽退（學員用手機）

1. 手機無痕開啟 `/volunteer/clock?site=SITE-MEAL`（或掃海報）  
2. 故意輸入錯誤身分證 → 應提示找不到  
3. 輸入 `A123456789` 登入 → 應顯示「測試送餐甲／送餐服務組」  
4. 按簽到 → 成功；再操作一次同一地點 → 應為簽退  
5. 回到 `/manager/attendance` 本月列表，可見「外勤QR」與簽退時間  

**通過標準**：同一人完成一輪簽到＋簽退；列表看得到。

### 9.7 實作四：公所刷證與月結（學員用電腦）

1. 承辦登入後開 `/office/kiosk`（未登入應被導去登入）  
2. 輸入或刷 `B234567894` + Enter → 簽到成功「測試內勤乙」  
3. 再刷／再送同一號 → 簽退成功  
4. 回 `/manager/attendance` 選本月 → **下載 Excel**，用 Excel／Numbers 開啟  
5. 確認表頭含：年月、組別、姓名、身分證字號、志工編號、日期、簽到／退時間、時數、簽到方式、地點、出勤編號；內容至少有外勤與刷證各一筆  

**通過標準**：刷證一輪完成；Excel 可開且欄位正確。提醒：檔案含身分證，僅供匯入既有系統，勿外流。

| P4 | 同一天可簽退且列表有紀錄 | ☐ |
| P5 | 公所刷證可簽到／簽退 | ☐ |
| P6 | 月結 Excel 可下載且欄位正確 | ☐ |
| P7 | （選）試算表「簽到退紀錄」看得到對應列 | ☐ |
| P8 | （選）名冊／派案／衛福部匯出頁仍可進，與出勤分開 | ☐ |

列印用完整步驟表、缺陷登錄、簽名欄：請開啟 [`volunteer-attendance-e2e-acceptance.md`](./volunteer-attendance-e2e-acceptance.md)。

### 9.9 訓練常見狀況（講師速查）

| 現象 | 處理 |
|------|------|
| 掃 QR 找不到志工 | 先完成 §9.5 建檔 |
| 外勤被導去登入頁 | 通知系統管理員檢查 middleware／正式站部署 |
| 刷證沒反應 | 確認已登入、游標在輸入框、掃描器為鍵盤模式（自動 Enter） |
| 名冊像假資料、非 GAS | 開 `/system/status`，應為 `gas_ready`；否則查 Vercel 環境變數 |
| 對方打不開 GitHub 文件 | 確認已邀為 Collaborator；或改傳本手冊 PDF／匯出副本（注意勿附 Token） |

### 9.10 技術管理員選修：自動化驗收腳本

僅在**已有專案與 `.env.local`** 的電腦執行（一般承辦訓練可跳過）：

```bash
cd /path/to/Elder-Visit-Platform
node scripts/verify-volunteer-attendance-flow.mjs
```

終端機出現 `"ok": true` 表示 GAS 端建檔、外勤／刷證簽到退、列表、Drive 月結鏡像可用。此腳本**不取代**上面的網站實作訓練。
